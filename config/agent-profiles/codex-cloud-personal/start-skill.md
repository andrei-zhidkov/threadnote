<!-- BEGIN THREADNOTE USER INSTRUCTIONS -->

Run `$HOME/.local/bin/threadnote cloud codex start`. If it fails, report the diagnostic and repair the environment;
do not claim memory is ready or fall back to unrelated storage.

Explicitly read `$HOME/.agents/skills/threadnote-context/SKILL.md` and
`$HOME/.agents/skills/threadnote-memory/SKILL.md`, then follow those instructions during this task.
This explicit loading is required even if hosted skill discovery does not expose these files automatically.
